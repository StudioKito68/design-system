# Polices

Le script cherche, dans l'ordre :

1. **Manuscrite (annotations, titre)** : `Caveat-Regular.ttf`, `Caveat[wght].ttf` ou
   `manuscrite.ttf` dans ce dossier, puis sur Mac *Bradley Hand*, *Noteworthy*,
   *Chalkboard*, sinon DejaVu Sans.
2. **Titre « STUDIO KITO »** : `titre.ttf` ici, sinon Futura / Helvetica (Mac), sinon DejaVu Sans Bold.
3. **Texte cartouche** : `texte.ttf` ici, sinon Helvetica / DejaVu Sans.

Recommandé : télécharger **Caveat** (licence libre OFL) sur
https://fonts.google.com/specimen/Caveat et déposer `Caveat[wght].ttf` ici,
pour un rendu manuscrit identique partout (Mac, claude.ai, Claude Code).
